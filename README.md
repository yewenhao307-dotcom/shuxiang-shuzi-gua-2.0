# 天地衍数 2.0

“数象”数字卦网站的独立整改版本。新版保留旧版数字卦算法、先天八卦数映射与六十四卦资料，重新设计了名称、首屏、起卦流程和结果信息结构。

## 启动

双击 `启动天地衍数.bat`，网站会自动在浏览器打开。也可以在本目录运行 `python server.py`。

## 算法

1. 第一组三位数除以 8，余数为下卦，整除按 8 计。
2. 第二组三位数除以 8，余数为上卦，整除按 8 计。
3. 第三组三位数除以 6，余数为动爻，整除按 6 计。
4. 先天八卦数：乾 1、兑 2、离 3、震 4、巽 5、坎 6、艮 7、坤 8。

所有输入和卦笺只保存在浏览器本地。流年、流月与卦象内容属于传统文化参考和自我反思工具，不是确定性预测。

结果页收录六十四卦共 384 条《周易》爻辞，并将原文与现代处境提示分层呈现。流月采用浏览器中国农历换算，不把公历月份直接等同于传统月令。

## 铜钱视觉依据

首页乾隆通宝依据国立台湾历史博物馆藏“清乾隆通宝制钱”（登录号 2004.052.0018，宝泉局，CC0）实物正面重制，钱文采用“上乾、下隆、右通、左寶”的真实对读方式。
